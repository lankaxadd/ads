# LankaAds 18+ Classifieds Web Application (v2 - With Main & Sub Images)

## Included Files
- `index.html`: Complete responsive multi-page web application (Home 18+ Classifieds with Main & Sub Image galleries, About & Pricing, Contact, User Login/Registration with NIC ID check, and Admin Dashboard).

## Key Features
1. **Main Image & Sub Images Support**: Upload a primary cover image plus up to 4 sub-images per ad with automatic client-side compression, interactive card thumbnail switching, and a full-screen photo gallery lightbox.
2. **Multi-Page Navigation**: Home, About & Pricing, Contact, Account (Login/Register), and Admin Panel.
3. **18+ Age Gate**: Mandatory 18+ confirmation modal before viewing listings.
4. **1 NIC ID = 1 Account**: Registration requires National Identity Card (NIC) number, username, and password, preventing duplicate NIC registrations.
5. **First 2 Days Free Trial**: Automatic 48-hour free period upon account creation, transitioning to a weekly LKR fee afterward.
6. **Mobile Response**: One-tap Call and WhatsApp buttons on every 18+ listing.
7. **Admin Dashboard**: Manage user roles (`USER`, `VIP`, `MODERATOR`, `SUSPENDED`), activate paid weekly plans, adjust weekly LKR rates, and moderate 18+ ads and photos.

## Deployment
Upload `index.html` directly to Netlify Drop, Vercel, GitHub Pages, or Firebase Hosting to get a live public URL.
